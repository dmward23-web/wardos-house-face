## Anti-text / anti-corny rules

1. **Strip label spam** — no duplicate titles, eyebrows, chips that say the same thing twice. Prefer silence.
2. **No merch-speak** — ban: Setlist, Track A, Side A, Encore, Press, Eras Stage, Tour Jar · Pressed, album-merch copy, star spam.
3. **Plain or none** — if a label must exist: Tonight / Next / Saved. Better: almost no labels; vinyl + numbers speak.
4. **Palette lock** — void `#0a0908` / `#010205` + amber `#f5c446` / `#ffe894` / `#b85a28` only. **Kill every pink / blush / lilac / magenta / rose / cyan tint.**
5. **Header** — logo-free · huge CT clock · Weather / Sensi ovals only. One identity line max (name *or* clock — not both stacked with chips).
6. **Day rail** — remove, or ≤3 unlabeled / minimally labeled instrument pills. No “DAY RECORD” banner.
7. **Jar** — one quiet strip · huge remaining numeral · no double label · no MUSTS/PRESS/JAR/PAYDAY tab row.
