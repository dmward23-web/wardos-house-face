# Hayes loot art (HAYESLOOT3)
Prism's painted set (source + anchors: /workspace/plates/2026-10-13/hayes-fortnite/prism/README.md, painted/ for glider + cards).
`1x/` and `2x/` hold identical names; 2x is used when devicePixelRatio > 1.4. Loaded only by `hayes-loot.js` on kid-hayes.html.
To swap a piece, drop a same-name, same-size, same-anchor PNG into both folders.
`callouts.js` = Hayes chore callouts (title + plain subtitle); doc for all kids: /workspace/plates/2026-10-13/kid-chore-callouts.md
